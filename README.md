# Bank Operations Widget

Проект для отображения банковских операций клиента.

## Установка

1. Установите Poetry: `pip install poetry`
2. Установите зависимости: `poetry install`
3. Активируйте виртуальное окружение: `poetry shell`

## Использование

Запустите главный модуль: `python src/main.py`

## Тестирование

Запустите тесты: `pytest`
