# Банковские транзакции

Программа для работы с банковскими транзакциями, предоставляющая функциональность фильтрации, поиска и анализа операций.

## Новая функциональность

### Поиск с использованием регулярных выражений
- Реализована функция `process_bank_search` для поиска транзакций по описанию
- Используется библиотека `re` для работы с регулярными выражениями
- Поиск выполняется case-insensitive

### Подсчет операций по категориям
- Реализована функция `process_bank_operations` для подсчета количества операций
- Используется `Counter` из библиотеки `collections`
- Поддерживает case-insensitive сравнение категорий

### Пользовательский интерфейс
- Интерактивное меню для выбора файлов данных
- Фильтрация по статусу, дате, валюте и ключевым словам
- Удобный вывод отформатированных транзакций
